# 简介

咸鱼云网盘目前是一个用于共享文件和实现私人网盘基本功能的系统，同时具有公共网盘与私人网盘，公共资源站与私有存储云两不误。

具有支持代理的离线下载，FTP/WebDAV访问，在线解压缩，文件搜索，文件收集，文件/目录分享，OSS对象存储挂载等功能。
> 部分功能由插件提供，见[在线文档](https://mjt233.github.io/saltedfishcloud-backend)的插件列表

在存储上支持原始目录存储（RAW）与相同文件集中存储（UNIQUE）两种文件存储组织模式，并能随时切换（不推荐的操作）。

## 具备的其他特性

- 兼容低版本到高版本的升级，自动更新数据库
- 构建与部署简单，大部分参数都能在运行期间通过管理员界面进行动态配置。
- 支持 Docker 部署
- 核心服务插件化动态功能拓展，支持基于微服务的动态服务扩展（见[微服务架构](#微服务架构)）
- 支持存储集群（需要MinIO或HDFS存储插件）
- 外部存储目录挂载（除本地文件系统存储外，其他存储需要通过插件提供支持）

目前支持挂载的存储见下表：

| 协议     | 拓展名称                 |
|--------|----------------------|
| HDFS   | sfc-ext-hadoop-store |
| MinIO  | sfc-ext-minio-store  |
| Samba  | sfc-ext-samba-store  |
| SFTP   | sfc-ext-sftp-store   |
| S3 OSS | sfc-ext-oss-store    |

目前支持外部访问的协议见下表：

| 协议     | 拓展名称               |
|--------|--------------------|
| FTP    | sfc-ext-ftp-server |
| WebDAV | sfc-ext-webdav     |

## 微服务架构

除主程序 `sfc-core` 外，后端能力还可拆分为独立微服务部署，与主程序协同运行：

- `sfc-gateway`：启用微服务模式时的整站统一入口，按服务发现自动路由到 core 或对应微服务
- 注册发现：默认使用 core 内置注册中心，多节点/容器化部署可切换 Nacos
- 现有服务：AI 助手（`sfc-ai-service`）、离线下载（`sfc-download-service`），可按需启用、自由组合

微服务的开发与部署见[微服务概述](develop/microservice/index.md)。
